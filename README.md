# PulseGuard (HeartRateWatch)

A training app for Wear OS watches, with an Android phone companion.

**Watch:** real-time heart-rate and pace threshold alerts, a break timer, distance tracking during a
run, and max-HR calibration.

**Phone:** settings and audio alerts; run history with route maps (including a 3D view), CSV
export/import, records and a fastest-1/5/10km leaderboard; a strength workout log with XP, levels,
ranks and streaks; a calorie tracker with nutrition-label scanning, a food database, a weight plan
that sets the daily goal, and a protein/carb/fat split; a weekly recap; and backup and restore.
